# 00｜工具总览（正文提炼版）

你关心的是“Claude Code 具备哪些工具，以及每个工具在系统中的职责”。
按能力分层如下：

## 文件与搜索层
- FileReadTool / FileEditTool / FileWriteTool / NotebookEditTool / GlobTool / GrepTool
- 特征：强调先检索、再读取、再修改，且控制结果规模。

## 执行层
- BashTool
- 特征：不是万能入口，而是受权限与沙箱约束的执行器。

## Web 信息层
- WebFetchTool / WebSearchTool
- 特征：先搜索定位来源，再抓取正文，避免直接盲抓。

## 任务流程层
- TodoWriteTool / EnterPlanModeTool / ExitPlanModeTool / Task 系列工具
- 特征：将复杂工作拆解为可追踪状态机（创建、更新、列出、停止、读取输出）。

## 协作层
- AgentTool / SendMessageTool
- 特征：支持子 Agent 调度和跨 Agent 通信。

## 交互与复用层
- AskUserQuestionTool / SkillTool
- 特征：信息不足时结构化提问，重复流程通过技能复用。

## 扩展接入层
- ListMcpResourcesTool / ReadMcpResourceTool / LSPTool
- 特征：通过外部资源与语义服务扩展能力边界。
