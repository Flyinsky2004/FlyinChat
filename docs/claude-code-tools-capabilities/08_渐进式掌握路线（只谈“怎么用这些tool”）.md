# 08｜渐进式掌握路线（内容细化版）

Phase 1：文件闭环
- 目标：稳定完成“定位文件 -> 阅读 -> 局部编辑/整写”。
- 工具：Glob、Grep、FileRead、FileEdit、FileWrite、NotebookEdit。

Phase 2：执行验证
- 目标：形成“修改 -> 运行 -> 反馈 -> 再修改”的工程闭环。
- 工具：Bash（配合文件工具）。

Phase 3：流程化任务
- 目标：复杂任务可拆解、可回放、可中断。
- 工具：TodoWrite、PlanMode、TaskCreate/Get/Update/List/Stop/Output。

Phase 4：信息与扩展接入
- 目标：接入外部知识与语义能力。
- 工具：WebSearch/WebFetch、MCP 资源工具、LSPTool。

Phase 5：并行协作
- 目标：主 Agent + 子 Agent 并行推进并汇总交付。
- 工具：AgentTool、SendMessageTool。
